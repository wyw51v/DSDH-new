01一、思想实验原典与展开

原典原文（节译）

设想我被关在一个房间里，不懂一个字的中文。房里有一本英文写的规则手册，告诉我当收到某种形状的符号时该如何回应。外面的人递进中文问题，我查手册、拼出中文符号递出去。我的回答可以好到让屋外人相信我懂中文——但我实际上一个字也不懂。 ——塞尔《心智、大脑与程序》（Minds, Brains and Programs），1980

提出者与论战

约翰·塞尔（John Searle，1932— ），美国哲学家。此文直接反驳当时强人工智能主张" + "「正确运行程序即具有心智」的观点。文章引发持续四十年的论战，是心灵哲学与 AI 哲学引用最多的文本之一。

思想实验的展开

  1. 句法 ≠ 语义：手册操作是句法（符号到符号），理解是语义（符号到意义）。前者不蕴含后者。
  2. 系统回复：反对者说：不是你懂中文，是" + "「你 + 手册 + 房间」整个系统懂。塞尔回答：让系统把手册全背下来、在脑子里操作，系统仍无理解。
  3. 机器人回复：给房间装上眼睛和手，让它能在世界中活动。塞尔坚持：仍只是更复杂的符号操作。
  4. 意识馆回复：把" + "「人」换成「神经元的系统性活动」，塞尔回应：模拟意识不等于意识，除非有因果能力。

常见误解

误解：" + "「塞尔是反 AI 的。」
正解：塞尔承认机器可以有心智，但反对" + "「仅凭程序」就够——需要因果与意向性。对数字人文更重要的启发是：统计方法处理的是符号，意义由人来承担。这不是贬低计算，而是划清责任边界。

02二、与教材的对接

教材节点游戏对应机制形成的判断
4.2 分词与预处理规则手册的「切分条款」分词表本身就是一套规则，不是中立的
4.3 词频 / TF-IDF / LDA手册中的计数与权重规则主题是算出来的，不是「读出来的」
4.4 命名实体识别「人名抽取条款」与遗漏的女性称谓NER 的漏抽是系统性的
4.6 语料偏见与客观幻象偏见版手册注入偏见藏在权重与规则里，不在数据里
一句话锚点：TF-IDF 与 LDA 不理解文本，它们高效地操作符号。理解与责任，始终在房间外的人那里。

03三、班级组织（40–45 人）

班级规模

40–45 人

10 组 × 4–5 人；每组内 2 人扮" + "「房间」、2–3 人扮「提问者」，第二轮互换。

房间侧

20–25 人

不许说话、不许解释，只递纸条。这是本场的硬规则。

提问侧

20–25 人

只看输出，写" + "「懂 / 不懂」判定与理由；第二轮负责溯源偏见。

大班关键：房间侧人数多，容易有人" + "「忍不住解释」。给房间侧发一张「禁语牌」，上面划掉" + "「我觉得」「意思是」，违规一次扣 5 分。

04四、学习目标

完成本场游戏后，学生应能：
  • 复述中文房间论证的核心：句法操作不等于语义理解（识记层）。
  • 执行纯规则驱动的文本处理，体验「输出正确但不理解」的状态（应用层）。
  • 溯源偏见是通过哪一条规则、哪一个权重进入结果的（分析层）。
  • 判断统计方法的「客观」幻象从何而来，并说明人文学者的理解在流程中的位置（反思层）。

06六、游戏流程

  1. 发手册、宣布禁语
    5′

    房间侧发正常版手册 A 与禁语牌；提问侧只拿输出表。强调：房间侧「只能查手册，不许用自己的理解」。

    教师引导语：「接下来 12 分钟，你就是一个不懂中文、但有一本很好用手册的人。请严格照做。」
  2. 第一轮盲操作
    12′

    发 S1–S4 四段史料。房间侧严格按手册输出主题与实体，不得解释、不得提问。提问侧只接收纸条。

  3. 图灵式判别
    8′

    提问侧只看输出，投票「屋里的人懂不懂这些文本」，并写下判断理由。揭晓：房间侧承认自己「一个字也没懂」。

    教师引导语：「输出这么准确，为什么说不懂？——这就是塞尔problem的核心。」
  4. 偏见注入：换手册
    12′

    教师「因印刷错误」换发偏见版手册 B，对同样四段文本重做。学生不知情。

  5. 揭底对读与溯源
    8′

    公开两版手册差异。各组对比两版输出，找出被「制造」的主题与「消失」的人物，填偏见溯源表。

  6. 收束：责任在谁
    5′

    回到 4.6：偏见不在语料里，而在规则与权重里。请学生写一句「人文学者在流程中的职责」。

08八、讨论引导（分层）

  1. 识记用一句话说出中文房间的核心论证：「句法」与「语义」的区别是什么？
  2. 分析房间侧输出正确却不理解——TF-IDF、LDA、NER 在哪些地方与它同构？
  3. 分析偏见是通过哪三条规则进入结果的？阈值、优先规则、抽取条款各造成了什么？
  4. 反思4.6 说「客观」是幻象——幻象藏在哪一层？语料、分词表、还是权重？
  5. 反思如果统计方法只处理符号，人文学者的「理解」在流程中处于什么位置？谁对结果负责？
  6. 反思与游戏 11（图灵测试）对读：能通过盲测的 AI，是否仍是「中文房间」里的那个人？

10十、伦理与安全红线

教学红线：①偏见版手册中的条款须明确标注为" + "「教学用合成样例」，课后收回，防止刻板印象外溢；②S3 涉及的女性守节叙事只用于演示抽取规则的技术后果，不得对历史人物做价值评判；③" + "「秘密换手册」是教学设计，揭晓后必须说明，不得让学生带着被欺骗感离场。

11十一、教师提示与变体

提示 1 · 控场要点
  • 禁语牌：房间侧每人一张，上面写" + "「不许说：我觉得 / 意思是 / 应该是」。这能保证游戏成立。
  • 换手册的时机：必须在第一轮判别" + "「房间侧其实不懂」这一刻之后，否则失去对照。
  • 人数多：提问侧可只收 3 组输出实物，其余组用投影统一展示，减少传纸条时间。
提示 2 · 变体与联动
  • 纯手工版：本手册即为纯手工版，无需电脑，适合机房不足的班级。
  • 代码版：第二环节用一段 20 行的 TF-IDF 代码替换手册，让学生看到" + "「手册就是代码」。
  • 三连问：04 中文房间 → 11 图灵测试 → 12 电车难题，分别追问" + "「懂不懂 / 像不像 / 该不该」，可作为期末复盘主线。
