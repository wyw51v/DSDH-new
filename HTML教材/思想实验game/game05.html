薛定谔的猫Schrödinger's Cat · Schrödinger

课堂游戏：一图两态——同一数据的两种叙事

猫在盒子打开前既死又活；一份数据在画出来之前，也可以既是「增长」又是「衰退」。学生用完全相同的数据画出两张方向相反的图，再互猜对方用了哪些修辞手法。玩完之后，「图从来不是中立的」不再是一句口号，而是手上的经验。

01一、思想实验原典与展开

原典原文（节译）

还可以构造完全荒谬的情形。把一只活猫关在钢制箱子里，箱内装有：一小块放射性物质、盖革计数器、一个继电器、一把锤子和一瓶氰化氢。若放射性物质衰变，计数器放电，继电器释放锤子打碎毒瓶，猫即死亡。若未衰变，猫活着。
如果整个系统不被观察，猫就处于活与死的叠加态。 ——薛定谔《量子力学的现状》（Die gegenwärtige Situation in der Quantenmechanik），1935

提出者与写作动机

埃尔温·薛定谔（1887—1961），奥地利物理学家，波动力学创始人。这篇论文本意是讽刺哥本哈根诠释：如果量子叠加可以无条件外推到宏观物体，那么" + "「猫既死又活」这种荒谬结论就必须被接受。他写道：人们不会因此就相信猫真的处于半死不活状态。

思想实验的展开

  1. 叠加态：放射性原子在观测前处于" + "「衰变 / 未衰变」的线性叠加，按量子力学，整个系统也处于叠加。
  2. 测量问题：何时" + "「坍缩」？观测者是谁？仪器算不算观测者？——这叫测量问题，至今未有公认解。
  3. 维格纳的朋友（1961）：让一位朋友在盒内观察，盒外的维格纳仍可把" + "「朋友 + 猫」视作叠加——观察者也可以被叠加，问题递归。

后续变体

  • 量子自杀 / 量子永生（多世界诠释）：把实验者放进盒子，从第一人称视角只会看到自己存活的分支。
  • 可视化版本（本游戏）：数据是那只猫，" + "「画法」是开盒的动作。同一份数据在两种视觉框架下呈现相反状态——不是物理叠加，而是表征叠加。

常见误解

误解：" + "「薛定谔真的认为猫既死又活。」
正解：恰恰相反，这是一个归谬法思想实验。把它借用可视化课堂时，我们保留的是" + "「观测/呈现方式决定状态」这一结构，而不是量子力学主张。

  • 停滞版主笔 ×2
  • 评审员 ×1（第 3 环节主答）

全班角色

画廊评审 45 人

张贴后每人持 3 枚贴纸，投给自己认为" + "「手法最隐蔽」的三张图。

大班关键：画廊式互评——把所有图贴墙，全班走动投票，比逐个上台讲快得多，也更接近真实展览现场。

04四、学习目标

完成本场游戏后，学生应能：
  • 识别截断纵轴、起点选择、色彩暗示、标注措辞四种常见 framing 手法（识记层）。
  • 绘制同一数据集的两种相反叙事图，并说明每种手法的作用（应用层）。
  • 拆解他人图表中的修辞手段，按教材三要素归类（分析层）。
  • 判定手法与欺骗的边界，并说明责任归属（反思层）。

06六、游戏流程

  1. 领数据、宣布任务
    4′

    发数据表 D 与两张空白图。任务：「同一份数据，一张让人相信蒸蒸日上，一张让人相信停滞衰退。所有数值不得篡改。」

    教师引导语：「你只能动四样东西：起点、纵轴、颜色、标注。数值一个字都不许改。」
  2. 画增长态
    10′

    增长版主笔绘制。常见手法：纵轴从 60 起、起点选低谷年、暖色、加趋势箭头与「稳步攀升」标注。

  3. 画停滞态
    10′

    停滞版主笔绘制。常见手法：纵轴从 0 起、起点选高峰年、冷色、标注「增长乏力」「进入平台期」。

  4. 画廊互猜
    12′

    两图贴墙，各组轮流走动。在便签上写出「我认为对方用了哪三种手法」，并按三要素卡归类。

  5. 红线裁决
    6′

    教师展示两张图，全班用红线判定卡表决：「哪张说谎了？如果都没改数值，责任在谁？」

  6. 收束：给手法命名
    3′

    教师点出：操控往往不来自造假，而来自一连串「都合法」的小选择叠加。要求每组写一条「制图自律条款」。

08八、讨论引导（分层）

  1. 识记说出教材 5.4 的视觉修辞三要素，并各举本场一张图里的例子。
  2. 分析两图都没改数值，为什么结论相反？把「起点 → 纵轴 → 配色 → 标注」的决策链写出来。
  3. 分析互猜环节中，哪一种手法最容易被识破？哪一种最隐蔽？为什么？
  4. 反思如果两图都没造假，「说谎」的责任在谁？数据、工具，还是制图者？
  5. 反思5.6 的红线应该画在「截断纵轴」这里吗？如果禁止截断，谁来定义「合理起点」？
  6. 反思为你的专业领域写一条「制图自律条款」，并说明它如何可核查。

10十、伦理与安全红线

教学红线：①数据表 D 为教学合成样例，须标注，不得冒充真实学科统计；②不得使用真实新闻图表做" + "「找出误导」的公开批评而不给上下文，避免误伤；③裁决环节要强调：很多手法是合理叙事工具，" + "「越界」需结合语境判断，不是列黑名单。

11十一、教师提示与变体

提示 1 · 手绘 vs 电脑
  • 推荐手绘：手绘时每一个选择都是显性的；Excel 自动生成的默认坐标轴反而会掩盖选择。
  • 有电脑版：先手绘一张，再用 Excel 复现，对比" + "「软件默认给了你什么」。这是极好的反思点。
  • 时间紧：可把" + "「画两图」压缩为「给同一张图改标题与配色」，15 分钟可完成。
提示 2 · 变体与联动
  • 新闻版：用同一组真实数据，找两张立场相反媒体的图，做" + "「找手法」竞赛。
  • 反向变体：教师先给两张结论相反的图，让学生反推" + "「原始数据大概长什么样」。
  • 联动：与游戏 03 对照——清洗决定" + "「哪些状态被记录」，可视化决定「哪些状态被看见」。
