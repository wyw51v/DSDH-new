01一、思想实验原典与展开

原典原文（节译）

如果一个智能在某一时刻知道所有驱动自然的力，以及构成宇宙的每一个物体的位置，并且它有足够的能力对这些数据进行分析，那么它就能用一个公式概括宇宙中从最巨大的天体到最微小的原子的全部运动；对它而言，未来与过去一样确定地呈现在眼前。 ——拉普拉斯《概率论的哲学论文》（Essai philosophique sur les probabilités），1814

提出者与背景

皮埃尔-西蒙·拉普拉斯（Pierre-Simon Laplace，1749—1827），法国数学家、天文学家，经典力学与概率论的奠基者之一。这段话是决定论最著名的表述：如果规律已知、初始条件完备，未来原则上完全可推演。注意：它与数学上的" + "「拉普拉斯变换」无关，后者是另一位数学家的工具。

思想实验的展开

  1. 全知的条件：需要" + "「所有力 + 所有位置 + 无限算力」三个条件同时满足——任何一个不满足，妖就不全知。
  2. 统计力学的反驳：麦克斯韦与玻尔兹曼说明：即使规律已知，面对 10²³ 个分子也只能谈概率，" + "「确定性」在操作层面无效。
  3. 量子力学的反驳：海森堡测不准原理表明，位置与动量无法同时精确获知——拉普拉斯妖所需的初始条件原则上不可得。
  4. 混沌理论：即使规律确定，初始条件的微小误差也会被指数放大（蝴蝶效应），长期预测不可能。

后续变体

  • 可计算性限制：图灵的停机问题说明，即使给定完整规则，某些问题也无法由算法判定。
  • 机器学习版本（本游戏）：一个模型" + "「知道」所有历史数据，却仍可能因为类别不平衡、时间穿越、结果泄露而给出毫无价值的" + "「高准确率」。全知不等于可靠。

常见误解

误解：" + "「拉普拉斯妖是机器学习的理想：数据够多就能预测一切。」
正解：它是决定论的可行性检验。本游戏借它的" + "「全知幻觉」做教学工具——让学生亲历：数据完备性的错觉，比数据不足更危险。

03三、班级组织（40–45 人）

班级规模

40–45 人

11 组 × 4 人 = 44；余 1 人任" + "「评估官」，专职发放评估卡。

组内角色

4 人 / 组
  • 全知妖 ×2（宣布预测与准确率）
  • 评估员 ×1（算混淆矩阵）
  • 解释员 ×1（读 SHAP 卡）

全班角色

评估官 1 人

按教师指令逐张发评估卡，制造" + "「逐层反转」的节奏。

大班关键：三张评估卡必须逐张发。每组先宣布" + "「95% 准确，预测成功」，再被打脸一次——三次反转是本游戏的全部戏剧张力。

04四、学习目标

完成本场游戏后，学生应能：
  • 计算混淆矩阵、精确率、召回率与 F1，说明准确率在类别不平衡下的失效（应用层）。
  • 识别时间穿越与结果泄露两类评估陷阱（分析层）。
  • 解读特征归因结果，指出模型所学的历史偏见（分析层）。
  • 论证可解释性是负责任研究的必需品而非装饰（反思层）。

06六、游戏流程

  1. 全知宣言：我能预测中举
    5′

    发数据集。各组扮演拉普拉斯妖，用 5 分钟「建模」——实际只需发现：全预测「不中」即可达 19/20 = 95% 准确率。宣布「预测成功」。

    教师引导语：「你是全知妖。给我一个准确率，证明你值得被信任。」
  2. 评估卡 E1：95% 陷阱
    8′

    揭示：20 条中仅 1 条「中举」。各组手算混淆矩阵、精确率、召回率、F1。看「成功」如何蒸发：召回率 = 0。

    教师引导语：「95% 的准确率，一个正例都没找出来。这个模型「优秀」在哪里？」
  3. 评估卡 E2：时间穿越
    8′

    揭示「试卷评定」是阅卷后给出的——它来自结果之后。用它做特征等于偷看答案。讨论：训练/测试的时间边界应如何划分？

  4. 评估卡 E3 + SHAP 卡
    12′

    发归因卡：最重要的特征竟然是「籍贯＝北」与「父辈任职」。解读：模型复制了历史的不平等，并把偶然相关当作规律。

  5. 给妖定罪
    8′

    对照 10.4/10.6，各组写「拉普拉斯妖判决书」：这个模型缺的是数据、方法，还是对不确定性的敬畏？

  6. 收束
    4′

    教师点题：拉普拉斯妖所需的初始条件原则上不可得；更重要的是，「全知」本身不构成正当性。为第 12 章的电车难题埋伏笔。

08八、讨论引导（分层）

  1. 识记写出混淆矩阵四格的含义，并说明精确率与召回率的区别。
  2. 分析为什么 95% 准确率可能毫无价值？用本数据的具体数字说明。
  3. 分析结果泄露与时间穿越有什么不同？各自的检测方法是什么？
  4. 分析10.6 「从历史数据学历史偏见」在本游戏中如何发生？哪些特征应当被禁用？
  5. 反思可解释性是装饰还是必需品？如果不发 SHAP 卡，你们会发现偏见吗？
  6. 反思拉普拉斯妖所需的三个条件（所有力 / 所有位置 / 无限算力）在现实中各缺什么？「全知」本身是否构成正当性？

10十、伦理与安全红线

教学红线：①籍贯、父辈任职等偏见特征只用于揭示模型机制，须明确标注为教学样例；②讨论中禁止把任何真实地域、群体与" + "「能力 / 品行」挂钩；③不得暗示" + "「某籍贯考生更优秀」这类结论，教师须在揭晓偏见特征时立即澄清其统计偶然性。

11十一、教师提示与变体

提示 1 · 教学节奏
  • 全知宣言要真：给 5 分钟让各组" + "「认真建模」，他们才会对 95% 产生真实自豪感——反转才有力量。
  • 指标可手算：20 条数据手算完全可行，不必用电脑。若用 sklearn 现场跑一遍，效果更强。
  • 时间紧：可只发 E1 与 E3 两张卡，保留" + "「准确率陷阱」与「偏见归因」两个核心点。
提示 2 · 变体与联动
  • 本地化：把" + "「科举中举」换成「论文是否被引」「档案是否被数字化」，学生会更关心结论的公平性。
  • 进阶：引入葛梯尔问题——" + "「得到证成的真信念仍可能不是知识」，与评估陷阱形成哲学呼应。
  • 联动：本场是游戏 12（电车难题）的前置——当模型" + "「全知但不正当」时，伦理决策才真正出现。
