01一、思想实验原典与展开

原典原文（形式版与通俗版）

设集合 S = { x ∣ x ∉ x }。那么 S ∈ S 吗？
若 S ∈ S，则按定义 S ∉ S；若 S ∉ S，则按定义 S ∈ S。矛盾。 ——罗素 1902 年致弗雷格的信；1903 年《数学原理》附录发表
某村只有一位理发师，他给且只给村里所有不给自己刮胡子的人刮胡子。那么，他给自己刮胡子吗？ ——罗素悖论的通俗版（" + "「理发师悖论」）

提出者与历史冲击

伯特兰·罗素（Bertrand Russell，1872—1970），英国哲学家、逻辑学家。1902 年他写信给弗雷格，指出《算术基础》的第五公理会导致矛盾。弗雷格在书出版时写下著名后记：" + "「一位科学家所能遭遇的最令人不快的事，莫过于在他工作接近完成时，发现其基础出了毛病。」这一发现直接催生了类型论与公理化集合论（ZF）。

思想实验的展开

  1. 朴素集合论的崩溃：" + "「任何性质都定义一个集合」这条看似无害的原则，会导致自指集合的矛瓦。
  2. 自指的结构：问题不在" + "「大」或「复杂」，而在允许一个集合把自身也作为成员。边界一旦不设防，体系就会吞掉自己。
  3. 解决方式：罗素的类型论禁止跨层自指；ZF 用分离公理限制集合构造。体系不是被" + "「修好」的，而是被「限制」的。

后续变体与关联

  • 说谎者悖论：" + "「这句话是假的」——自指在语言层面的版本。
  • 葛梯尔问题（1963）：" + "「得到证成的真信念」仍可能不是知识——与游戏 10 的评估陷阱呼应。
  • 本体设计（本游戏）：" + "「本体中能否有一个类，其实例包含本体自身？」——RDF/OWL 必须给出答案。

常见误解

误解：" + "「理发师悖论只是文字游戏，现实中哪有这样的理发师。」
正解：它揭示的是任何形式系统的根本限制。在知识图谱里，" + "「收录所有不收录自己的目录」这样的本体需求完全可能出现——这不是哲学虚构，是真实的数据建模难题。

04四、学习目标

完成本场游戏后，学生应能：
  • 设计一个含类、属性与关系约束的小领域本体（应用层）。
  • 识别本体中的自指与边界漏洞，并给出形式化的补丁（分析层）。
  • 说明每个补丁排除了什么情况、代价是什么（分析层）。
  • 论证「本体即世界观」不是修辞而是技术事实（反思层）。

06六、游戏流程

  1. 搭本体：小文人圈知识图谱
    10′

    各组为「明末文人圈」设计本体：类（人 / 机构 / 事件 / 作品）、属性（生卒、籍贯、任职）、关系（交游 / 师长 / 撰写）。画成类图并写出约束。

  2. 第一张悖论卡：自指目录
    8′

    发 P1：「本品目收录所有不收录自己的目录」。各组必须现场改本体，写补丁理由。

    教师引导语：「你的本体里，「目录」这个类能不能有一个实例是它自己？如果能，悖论就进来了。」
  3. 第二张卡：虚构的集体笔名
    8′

    发 P2：「'某'是一个虚构的集体笔名，但它署名了 30 部作品」。要求处理实体对齐问题。

  4. 第三张卡：自指关系
    8′

    发 P3：「关系'影响了'能不能指向自身？」这是一个技术性很强的问题，对应 OWL 的自反性约束。

  5. 补丁答辩
    6′

    每组 1 分钟：加了什么约束、排除了什么、代价是什么。教师追问「被排除的情况里有没有真实史料」。

  6. 互找漏洞 + 回到 9.6
    5′

    交换本体，专找对方的「无法归类的对象」。全班一句话总结：为什么本体即世界观。

08八、讨论引导（分层）

  1. 识记用一句话写出罗素悖论的形式表达，并解释「理发师」版本为何等价。
  2. 分析P1 的补丁排除了什么？被排除的情况里，有没有真实存在的目录需求？
  3. 分析P2 的「集体笔名」在你的本体里属于哪一类？如果不属于任何类，说明什么？
  4. 反思本体为什么是「世界观」而不是「客观分类」？你的补丁体现了什么价值取舍？
  5. 反思RDF 三元组能不能表达「这句话是假的」？如果不能，图谱的边界在哪里？
  6. 反思9.6 说「本体即世界观」——请用一个你自己的例子说明：不描述什么，也是一种立场。

10十、伦理与安全红线

教学红线：①" + "「集体笔名」案例须标明为教学样例，不得用于对真实作者的身份判断；②讨论" + "「空类」时不得涉及对任何族群或群体的价值判断；③本游戏涉及的形式化约束只需直觉理解，不要求掌握 OWL 语法，避免超出学生基础。

11十一、教师提示与变体

提示 1 · 难度调节
  • 基础较弱：只用 P1 理发师卡，围绕" + "「人」这个类反复追问即可，40 分钟足够。
  • 进阶：引入 OWL 的" + "「类不能是自身的实例」约束与自反关系定义，把悖论落到具体语义技术。
  • P3 提示：若学生卡住，提示" + "「自反关系」在 OWL 中是可以声明的——问题不是能不能表达，而是表达后语义是否荒谬。
提示 2 · 变体与联动
  • 真实案例：用出版史中真实存在的集体笔名（如" + "「某丛书编委会」）替换虚构样例，说服力更强。
  • 联动：与游戏 07（平面国）呼应——" + "「每一层视角都有自己的盲区」与「每个本体都有自己的边界」是同构的。
  • 延伸：让学生查一个真实本体的" + "「排除条款」（如某数据库的收录标准），看它如何表达世界观。
