01一、思想实验原典与展开

原典原文（大意）

忒修斯返回的船，后来被雅典人一代代保存：朽坏的木板被新木替换，旧的被拿走。久而久之，船的所有部件都换过一遍。于是哲学家争论：这还是原来那艘忒修斯之船吗？有人说仍是，有人说已不是。 ——普鲁塔克《希腊罗马名人传·忒修斯传》第 23 节

提出者与流传

普鲁塔克（约 46—120 年），罗马时代的希腊史家。他记录这则传说时，它已是学园派争论的旧题；后来经霍布斯、洛克、休谟反复讨论，成为" + "「同一性」（identity）最经典的思想实验。洛克用它区分" + "「同一的人」与「同一的物质」，霍布斯则把它推到极端：若旧木板被别人捡去拼成另一艘船，哪一艘才是真的？

思想实验的展开

  1. 逐步替换：每次只换一块板，任何一步看起来都" + "「还是那艘船」——但累积起来，全部都换了。这是典型的" + "「谷堆式」连续变化（见游戏 13）。
  2. 判据之争：同一性来自物质（木板）、形式（船的结构），还是历史（连续的传承链）？三套判据给出三种答案。
  3. 霍布斯难题：旧木板被组装成第二艘船，两艘都声称自己是原船——同一性不再唯一。

后续变体

  • 祖父的斧头：换了三次柄、两次刃，还是祖父那把斧头吗？（日常版本）
  • 企业并购：一家公司的资产、员工、名称、办公地全部更替后，还是同一家公司吗？（法人身份）
  • 数据集版本（本课程版本）：原始扫描 → OCR → 去重 → 模型标注 → 人工复核，每一轮都在" + "「换板」。第 v5 版数据还是第 v1 版吗？答案不在内容，而在版本链。

常见误解

误解：" + "「内容一样就是同一份数据」。
正解：内容相同但来源、许可、处理方式不同的两份数据，在法律与学术意义上是不同的数据。教材 2.4 的来源谱系与 2.7 的数据护照，正是对" + "「历史判据」的制度化回答。

02二、与教材的对接

本游戏把第 2 章的数据来源谱系与合规要求做成一套" + "「海关流程」：

教材节点游戏中的对应物形成的判断力
2.2 五种类型 / 2.3 结构化程度判断手上的「船」属于文本、图像还是衍生数据给数据分类的语言
2.4 来源谱系D1→D4 四轮换板区分原生数字 / 数字化副本 / 衍生数据
2.5 合规获取与红线红线卡与海关裁决知道什么情况下必须扣留
2.7 数据护照每轮填写一份护照用字段而非直觉记录改动链
一句话锚点：同一性不来自内容，来自可追溯的改动链。数据护照不是行政表格——它是忒修斯之船的答案。

04四、学习目标

完成本场游戏后，学生应能：
  • 区分原生数字、数字化副本与衍生数据三类来源（识记层）。
  • 填写一份包含来源、许可、改动方式、复核状态的数据护照（应用层）。
  • 判断何种情况下衍生数据必须重新取得授权或扣留使用（分析层）。
  • 论证「同一性来自改动链而非内容」这一判断，并用本轮护照作证（反思层）。

06六、游戏流程

  1. 初始登记：给原船办护照
    6′

    发 D1（某县志扫描件说明）。各组填写第一份护照：来源、年代、许可、格式、责任人。海关总署抽查 2 组。

    教师引导语：「先别想后面。假设这就是你手上唯一的资料，你敢在论文里用它吗？凭什么敢？」
  2. 第一轮换板：扫描 → OCR
    6′

    发 D2（OCR 文本）。各组对比 D1 更新护照，新增「转换方式」与「信息损失」字段，投票是否仍是原船。

  3. 第二轮换板：清洗与规范化
    6′

    发 D3（删除页码、规范异体字、合并字段）。护照须新增「删除项清单」。教师追问：页码不是内容，删掉它算不算改动？

  4. 第三轮换板：模型标注
    6′

    发 D4（含 2 处故意标错的人物标注）。护照须新增「衍生方式」和「人工复核状态」。

    教师引导语：「模型替你读了这份志书。你打算在论文里怎么交代这件事？」
  5. 红线卡裁决
    10′

    发三张红线卡。海关总署逐组检查四份护照，判定「放行 / 扣留 / 复议」。抽 3 组申诉，每组 30 秒。

  6. 画同一性曲线、收束
    6′

    各组在白纸上画出四轮的「仍是原船」信心值折线。教师揭示：曲线人人不同，但护照字段应该人人相同——这就是可复现。

08八、讨论引导（分层）

  1. 识记说出原生数字、数字化副本、衍生数据三者的区别，各举本游戏中的一个版本。
  2. 分析四轮中护照的哪个字段最关键？为什么「许可」不会因内容相同而自动继承？
  3. 分析霍布斯难题里两艘船都声称自己是原船——在数据世界里，对应的情形是什么？
  4. 反思什么时候衍生数据必须重新授权？「我只是转了个格式」能成为理由吗？
  5. 反思数字人文里是否存在合理的「原件崇拜」？当原件已佚，副本的合法性从何而来？
  6. 反思你的四轮信心曲线形状如何？为什么曲线可以不同，而护照字段应当相同？

10十、伦理与安全红线

教学红线：①D4 中的 2 处错标必须明确标注为" + "「教学用合成样例」，课后收回，严禁带入真实研究；②不得使用来源不明或许可不清的志书图像作为 D1；③海关裁决模拟的是合规判断流程，不构成法律意见，教师须在结束时说明。

11十一、教师提示与变体

提示 1 · 差异化与控场
  • 快组加码：追加" + "「霍布斯卡」——把 D1 的旧木板（被删的页码与圈点）交给另一组，请他们论证自己那艘才是原船。
  • 慢组支架：护照表可先发" + "「填写示例」半页，标明「来源」一栏怎么写。
  • 计时：每轮 6 分钟用投影倒计时，时间到统一停笔，避免组间进度差拉大。
提示 2 · 变体
  • 生活版：把" + "「船」换成自己的手机相册——原图、压缩图、加滤镜、AI 修图，同一性追问会立刻变得切身。
  • 进阶版：引入真实版本控制概念（git / DOI / 数据引用），说明学术出版界的" + "「数据护照」长什么样。
  • 联动：与游戏 13（谷堆悖论）共享" + "「连续变化何时质变」的结构，可在期末复盘时并置。
