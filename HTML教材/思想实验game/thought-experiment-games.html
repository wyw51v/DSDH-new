01

庄周梦蝶 Zhuangzi's Butterfly Dream

对接 第1章 导论：当数据科学遇见数字人文 ｜ 游戏：数据身份盲盒——你是庄周，还是那只蝶？

原典与核心问题

《庄子·齐物论》：庄周梦见自己化为蝴蝶，醒来后"不知周之梦为胡蝶与，胡蝶之梦为周与"。核心一问：你以为看到的"实在"，是否只是某种视角下的呈现？

教材对接：1.2 两个主角；1.3 三种相遇方式（方法下沉 / 问题牵引 / 反思升维）；1.4 可复现、案例真实、伦理在场。伦理落点：承认视角的存在，是"伦理在场"的第一步。

时长30–35 分钟
分组4–6 人/组
形式身份盲盒 + 双视角写作 + 全班表决
难度★☆☆☆☆

游戏流程

  1. 发身份（3′）：每人抽一张身份卡——"庄周卡"（人文研究者：追问意义、语境、价值）或"蝴蝶卡"（数据/算法视角：只看可得、可测、可算）。身份保密，自己知道即可。
  2. 看同一份证据（7′）：每组发同一套"证据卡"：一张地方志目录的统计表 + 一页原始档案图片 + 一段学者释读。所有组别看到的材料完全相同。
  3. 第一写作（6′）：按自己身份写"我看到了什么？这是什么？"——庄周卡必须写意义与语境，蝴蝶卡必须写模式与数值，不许越界。
  4. 交换身份（3′）：组内互换身份卡，面对同一套证据再写一遍（6′）。
  5. 对读与表决（10′）：组内对照两版答案，标出"冲突点"与"只有某个视角才看得到的东西"；每组推一份"最像真实的描述"上台，全班投票。

材料与道具

  • 身份卡两套（庄周/蝴蝶）
  • 证据卡：统计表 + 档案图 + 释读各 1
  • 双视角观察表（两栏对照）

判定与产出

  • 胜出标准不是"答对"，而是冲突点找得最准
  • 产出：双视角观察表 + 3 条冲突点
  • 加分：说出"哪个视角在系统性地漏掉什么"

讨论引导

  • 数据科学给的是"蝶的视角"还是"庄周的视角"？两者能互相替代吗？
  • 1.3 的三种相遇方式（方法下沉 / 问题牵引 / 反思升维），分别站在哪一边？
  • 如果"看的方式"决定了"看到的东西"，为什么教材仍承诺"可复现、案例真实"？（提示：可复现约束的是方法，不是视角。）

教学提醒：此游戏容易被学生玩成"玄学"。主持人要在最后 3 分钟拉回教材：视角多元 ≠ 事实相对主义；承认视角，是为了更诚实地标注局限。

教师提示与变体

变体：把身份卡换成"第1章三种相遇方式"卡，让答案直接对应课程知识点。线上版：用腾讯文档分栏，两人同时编辑，冲突处自动高亮。延伸作业：写 300 字《我作为庄周/蝴蝶的观察声明》，作为课程档案。

02

忒修斯之船 Ship of Theseus

对接 第2章 人文数据的类型与获取 ｜ 游戏：数据海关——给忒修斯之船签发护照

原典与核心问题

普鲁塔克记载：忒修斯的船被逐年更换木板，最终所有部件都不是原来的——它还是那艘船吗？核心一问：当一个对象的所有组成部分都被替换，它的"同一性"由什么维系？

教材对接：2.2 五种类型；2.3 结构化程度；2.4 来源谱系（原生数字 / 数字化副本 / 衍生数据）；2.5 合规获取；2.7 数据护照。伦理落点：来源不清的数据，不能仅凭"内容一样"就当作同一份。

时长35–40 分钟
分组3–4 人/组
形式四轮换板 + 护照填写 + 同一性投票
难度★★☆☆☆

游戏流程

  1. 初始登记（5′）：教师展示"原始船"——某地方志的扫描件，各组为它签发第一份数据护照：来源、年代、许可、格式、责任人。
  2. 第一轮换板（6′）：换成 OCR 文本。各组更新护照：增加了什么？丢失了什么？投票"还是不是原来的数据"。
  3. 第二轮换板（6′）：删除页码与版式信息，合并字段，规范异体字。再次更新护照并投票。
  4. 第三轮换板（6′）：加入模型自动校勘的标注（其中 2 处故意标错）。护照必须新增"衍生方式"和"人工复核状态"。
  5. 海关裁决（10′）：教师出示"红线卡"：若来源许可不明 / 若衍生数据未标注 / 若模型输出未经复核。各组判断本轮护照是否"准予通关"，并说明放行或扣留的依据。

材料与道具

  • 同一文献的 4 个版本（扫描/OCR/清洗/标注）
  • 空白数据护照 4 份/组
  • 红线卡 3 张

判定与产出

  • 胜出：护照字段最完整、改动链最清晰
  • 产出：4 轮护照 + 一条"同一性判定曲线"
  • 扣分：任何一轮漏填"衍生方式"

讨论引导

  • 四轮里，护照的哪个字段最关键？为什么"许可"不会因为内容相同而自动继承？
  • 什么时候衍生数据必须重新取得授权？"我只是转换了格式"能成为理由吗？
  • 数字人文里是否存在合理的"原件崇拜"？当原件已佚，副本的合法性从何而来？

与教材的勾连：2.7 的"数据护照"不是行政表格，而是忒修斯之船的答案——同一性不来自内容，来自可追溯的改动链。这句话值得板书。

教师提示与变体

变体：把"船"换成学生自己的手机相册——原图、压缩图、加滤镜图、AI 修图，同一性追问会立刻变得切身。 caution：第三轮的错标必须提前准备并明确告知"这是教学用的合成样例"，避免学生误信为真史料。

麦克斯韦妖 Maxwell's Demon

对接 第3章 数据处理基础：Python 与 pandas ｜ 游戏：人肉 pandas——麦克斯韦妖清洗大赛

原典与核心问题

麦克斯韦 1867 年设想：一个能分辨分子快慢的小妖精把快分子与慢分子分到两边，似乎不耗功就降低了熵。核心一问："分类"需要知道什么？规则的代价藏在哪里？

教材对接：3.3 pandas 三件套；3.4 数据清洗四板斧（缺失、重复、格式、字段）；3.6 可复现即学术诚信。伦理落点：清洗不是擦除，规则必须被写下并被别人复现。

时长40–45 分钟
分组4 人/组（两两互检）
形式卡片分拣 + 伪代码日志 + 交叉复现
难度★★☆☆☆

游戏流程

  1. 领脏数据（5′）：每组一叠卡片，对应教材四个真实案例：形成时间缺失、合并目录后的重复记录、编年中年份格式不一、人物表与作品表字段名不一致。
  2. 妖精分拣（12′）：不许写代码，只用卡片手工执行四板斧。每执行一步，必须在"操作日志"上写清楚伪代码，例如 df.drop_duplicates(subset=['题名','责任者'])。
  3. 封存交接（3′）：把清洗后的卡片与操作日志一起封袋，交给相邻组。
  4. 交叉复现（12′）：接收组只能看日志，不能看原卡片的处理结果，尝试从原始脏卡片复现出同样结果。记录"日志没写清而卡住"的地方。
  5. 记分揭晓（8′）：双计分：清洗准确率 + 复现成功率。复现失败的一方要指出"妖精的规则漏在哪"。

材料与道具

  • 脏数据卡片 40–60 张/组（含 4 类问题）
  • 操作日志模板（步骤 / 规则 / 伪代码）
  • 封袋与计分表

判定与产出

  • 胜出：准确率 × 复现率 最高组
  • 产出：清洗结果 + 可复现操作日志
  • 特别奖：找出最多"规则歧义"的组

讨论引导

  • 妖精分拣前必须"知道"什么？如果规则里没写"民国 38 年≈1949 年"，会发生什么？
  • 为什么操作日志 = 可复现 = 学术诚信？把这三件事画成一条因果链。
  • 清洗有没有"制造"数据？你删掉的那张重复卡，会不会恰好是一条独立证据？

教师点睛：麦克斯韦妖的现代答案是"信息也是有代价的"——获取规则、记录规则、擦除记忆都要付出代价。这正是 pandas 日志的意义：清洗的代价必须被记账。

教师提示与变体

无电脑版：全程用卡片完成，伪代码写在纸上即可。有电脑版：第二环节改用 Jupyter 现场跑，把复现变成真正的 notebook 交接。进阶：给不同组发放略有差异的"规则手册"，观察清洗结果如何因规则不同而分叉。

中文房间 Chinese Room · Searle

对接 第4章 文本挖掘与 NLP ｜ 游戏：规则手册盲操作 + 偏见注入

原典与核心问题

塞尔 1980 年：一个不懂中文的人待在房间里，按规则手册对递进来的中文符号作出恰当回应，屋外人以为他懂中文。核心一问：正确地处理符号，等于理解吗？

教材对接：4.2 分词与预处理；4.3 词云 / TF-IDF / LDA；4.4 命名实体识别；4.6 语料偏见与"客观"幻象。伦理落点：统计上的"客观"，可能只是规则手册里的权重偏见。

时长45 分钟
分组4 人/组（房间组 vs 提问组）
形式规则盲操作 + 图灵式判别 + 偏见注入
难度★★★☆☆

游戏流程

  1. 发手册（5′）："房间组"拿到一本极简规则手册：出现"灾荒/饥馑/赈济"≥2 次 → 主题判为灾荒；"字/号"前有二字人名 → 抽为人名；出现"奏/疏"→ 判为公文。手册之外一律不许用自己的理解。
  2. 盲操作（12′）：发 4 段真实史料片段，房间组严格按手册输出主题与实体，不得解释、不得查工具。
  3. 判别（8′）："提问组"只看输出，投票判断：屋里的人"懂不懂"这些文本？写下判断理由。
  4. 偏见注入（12′）：教师给房间组换一本"偏见版手册"——把"灾荒"类的权重悄悄调高、把女性称谓规则删掉。对同一批文本重做一遍。
  5. 揭底对读（8′）：对比两版输出，找出被"制造"出来的主题与"消失"的人物。提问组判定：这个房间的回答，客观吗？

材料与道具

  • 规则手册（正常版 / 偏见版）
  • 真实史料片段 4 段（含 1 段女性人物材料）
  • 主题与实体输出表

判定与产出

  • 胜出：找出最多偏见痕迹的组
  • 产出：两版输出对照 + "理解/处理"判定表
  • 必答：偏见是通过哪条规则进入结果的？

讨论引导

  • TF-IDF、LDA、NER 到底"理解"文本了吗？还是更高级的中文房间？
  • 4.6 说"客观"是幻象——偏见藏在哪一层？语料、分词表、还是权重？
  • 如果统计方法只是处理符号，人文学者的"理解"在流程中处于什么位置？

伦理提醒：偏见版手册中的规则需明确标注为"教学用合成样例"，课后收回，避免学生把其中的刻板印象当作史实。

教师提示与变体

与第11章联动：本游戏是"中文房间"的手工版，第11章的"盲测裁判"是它的 LLM 版；两场连上，塞尔之问与大模型的"理解"之争会形成完整闭环。线上版：用表单收集输出，匿名后投影判别。

薛定谔的猫 Schrödinger's Cat

对接 第5章 数据可视化与视觉修辞 ｜ 游戏：一图两态——同一数据的两种叙事

原典与核心问题

薛定谔 1935 年：盒子里的猫在打开之前处于死与活的叠加态。核心一问：在观测/呈现之前，对象有没有唯一确定的状态？谁决定了它被看成什么？

教材对接：5.1 图从来不是中立的；5.3 叙事可视化与 framing；5.4 视觉修辞三要素（路径 / 视角 / 色彩）；5.6 误导与操控的红线。伦理落点：数据没变，图却说了两个故事——责任在呈现者。

时长45 分钟
分组2–3 人/组
形式同数据双叙事 + 手法互猜 + 红线判定
难度★★☆☆☆

游戏流程

  1. 领同一份数据（3′）：每组拿到完全相同的真实数据表（如某学科 20 年论文数量，含起伏）。
  2. 画"增长态"（10′）：要求用尽合法手段让图看起来"蒸蒸日上"：截断纵轴、选有利起点、换配色、加趋势注解。
  3. 画"停滞态"（10′）：同一份数据，让图看起来"停滞甚至衰退"：换起点、改比例尺、用冷色、换标注措辞。
  4. 手法互猜（12′）：组间交换两图，接收方必须指出对方用了哪些修辞手段，并按教材 5.4 的"路径/视角/色彩"三要素归类。
  5. 红线裁决（10′）：全班投票：哪张图"说谎"了？如果两张图都没改数据，谁该为误导负责？对照 5.6 给出判定。

材料与道具

  • 真实数据表 1 份/组
  • 坐标纸与彩笔（无电脑版）或 Excel/绘图工具
  • 三要素对照表 + 红线判定卡

判定与产出

  • 胜出：两图差异最大且都能自圆其说
  • 产出：两张图 + 修辞手法对照表
  • 必答：哪一处是"手法"，哪一处已是"欺骗"？

讨论引导

  • "猫"到底死还是活？同一份数据为什么能支撑相反结论？
  • 如果都没篡改数值，误导的责任在谁——数据、工具、还是制图者？
  • 教材 5.6 的红线，你认为应该画在"截断纵轴"这里吗？为什么？

教师点睛：薛定谔用猫讽刺量子力学的"观测决定状态"；可视化课堂则把它翻转过来——不是观测决定了数据，而是呈现决定了公众看到的数据。这一句可作为本章的收束。

教师提示与变体

延伸：让学生找一张真实新闻图表，反向拆解其 framing，与自己的两张图并排展示。评价提示：提醒学生"合法手法"与"红线"的边界常常是争议点，争议本身就是最好的讨论材料，不必急着统一答案。

原典与核心问题

艾博特 1884 年《平面国》：二维世界的居民无法理解"上/下"，直到一个球体闯入。核心一问：你的表征维度，是否决定了你能看见什么、看不见什么？

  • 时间纸条 + 行政层级卡

判定与产出

  • 胜出：结论翻转最有据且地图声明最诚实的一组
  • 产出：二维/三维结论对照表 + 地图声明

讨论引导

  • 二维地图漏掉了什么？加上时间后，因果关系如何改变？

教师点睛：《平面国》的原作是维多利亚时代的等级讽刺小说——"二维居民看不见第三维"与"史料只记录某一阶层的空间经验"是同构的。加一维，不只是加一个变量，而是加一种伦理立场。

缸中之脑 Brain in a Vat · Putnam

普特南 1981 年：一个大脑被置于营养液中，由计算机供给全部感官信号，它如何知道自己不在"真实世界"？核心一问：仅凭接收到的信号，能否判断所见为实？

分组3–4 人/组
形式盲注 + 可信度打分 + 揭晓对账 + 核验工具
难度★★★☆☆

游戏流程

  1. 盲注（12′）：教师展示 6 张影像，不给任何来源信息：2 张真实历史照、2 张同图的裁剪/调色/篡改版、2 张 AI 生成或风格化图。各组像"缸中的分析师"一样写图注：时间、地点、人物、事件，并给可信度 0–10 分。

  • 盲注表（图注 + 可信度）

判定与产出

  • 胜出：误信率下降幅度最大的组
  • 产出：图注表 + 核验前后对照 + 使用守则

  • 只看像素，能否判断真伪？"缸中之脑"的困境与图像模型的局限有什么相通？
  • 8.7 任务二要求"生成影像图注并人工复核"——为什么人工复核不可替代？

教师提示与变体

罗素悖论 Russell's Paradox / Barber

对接 第9章 知识图谱与语义技术 ｜ 游戏：理发师的本体——给你的图谱划边界

原典与核心问题

罗素 1901 年，通俗版即"理发师悖论"：给且只给不给自己刮胡子的人刮胡子的理发师，该不该给自己刮胡子？核心一问：当分类规则把自己也卷进去时，体系会怎样崩溃？

教材对接：9.1 把零散事实连成网络；9.2 URI / RDF / 本体；9.3 本体设计（类、属性、关系）；9.4 图谱构建与对齐；9.6 本体即世界观。伦理落点：本体不是客观分类，它是一套关于"什么存在、如何相关"的承诺。

分组3–4 人/组
形式本体搭建 + 悖论卡冲击 + 补丁答辩 + 互找漏洞
难度★★★★☆

游戏流程

  1. 搭本体（10′）：各组为"某一文人圈子"设计一个小本体：类（人 / 机构 / 事件 / 作品）、属性（生于、任职、参与、撰写）、关系约束。画成类图。

  3. 补丁答辩（8′）：各组用 1 分钟说明：你加了什么约束、排除了什么情况、代价是什么（例如：排除自指会漏掉真实的自传性写作吗？）。
  4. 互找漏洞（10′）：组间交换本体，专门寻找对方体系里的"自指漏洞"或"无法归类的对象"，找到最多者胜。

  • 本体设计模板（类/属性/关系三栏）
  • 悖论卡 3 张 + 追加卡若干
  • 大白纸与便签

判定与产出

  • 胜出：补丁最简洁且代价说明最诚实
  • 产出：本体图 + 悖论处理说明
  • 加分：主动指出自己本体的一个漏洞

讨论引导

  • 本体为什么是"世界观"而不是"客观分类"？你的补丁体现了什么价值取舍？
  • 遇到自指与边界案例时，分类体系必须做什么让步？这些让步影响谁？
  • RDF 三元组能不能表达"这句话是假的"？如果不能，图谱的边界在哪里？

拉普拉斯妖 Laplace's Demon

对接 第10章 机器学习与深度学习基础 ｜ 游戏：全知妖的考试——评估卡反转

原典与核心问题

拉普拉斯 1814 年：若有一个智能知道每一粒子的位置与动量，它就能用同一套规律推演全部未来与过去。核心一问：如果"全知"真的可能，预测还是不是知识？

教材对接：10.2 监督学习；10.3 无监督学习；10.4 评估：准确率之外；10.5 可解释性（SHAP 与注意力）；10.6 从历史数据学的"历史偏见"。伦理落点：高准确率不等于有用，更不等于正当。

时长45 分钟
分组3–4 人/组
形式全知承诺 → 评估卡反转 → 指标重算 → SHAP 归因
难度★★★★☆

游戏流程

  1. 全知宣言（5′）：各组扮演"拉普拉斯妖"，拿到一份历史数据（如某时期科举及第者特征表）与一个任务："预测谁会中举"。给 5 分钟，让他们宣布自己模型的准确率并夸口"预测成功"。
  2. 第一张评估卡（8′）：教师揭示：及第率仅 3%，全预测"不中"就有 97% 准确率。各组重算混淆矩阵、精确率、召回率、F1，看"成功"如何蒸发。
  3. 第二张评估卡（8′）：揭示"时间穿越"：训练数据来自后世，测试数据来自前世。讨论：这种高精度是预测还是作弊？
  4. 第三张 SHAP 卡（12′）：教师给出该模型的"归因结果"：最重要的特征竟然是"籍贯属于某地区"或"父辈是否任职"——即历史偏见本身。各组解释：模型学到了什么？它在复制怎样的不平等？
  5. 给妖定罪（8′）：对照 10.4 与 10.6，各组写一份"拉普拉斯妖判决书"：这个模型缺的是数据、是方法，还是对不确定性的敬畏？

材料与道具

  • 历史数据集（含类别不平衡与偏见特征）
  • 评估卡 3 张 + 混淆矩阵模板
  • SHAP 归因示意卡

判定与产出

  • 胜出：最早发现"97% 准确率陷阱"的组
  • 产出：前后评估对照表 + SHAP 归因说明 + 判决书
  • 加分：主动指出自己模型的伦理风险

讨论引导

  • 为什么高准确率可能毫无价值？"全知"做不到，缺的是数据，还是不确定性本身？
  • 10.6 "从历史数据学历史偏见"在这个游戏里是如何发生的？有哪些特征应当被禁用？
  • 可解释性是装饰，还是负责任研究的必需品？如果不给 SHAP 卡，你们会发现问题吗？

教学红线：偏见特征（籍贯、性别、族属）只用于揭示模型机制，必须明确声明为教学样例；讨论中禁止把任何真实群体与"能力/品行"挂钩。

教师提示与变体

无电脑版：全部数值由教师卡片给出，学生手算混淆矩阵即可。有电脑版：用 sklearn 现场跑一遍，让学生亲手看到 97% 的"优秀"模型。跨章联动：本游戏是第12章"电车难题"的前置——当模型"全知但不正当"时，决策的伦理问题才真正出现。

图灵测试 Turing Test · Imitation Game

对接 第11章 大语言模型与生成式 AI ｜ 游戏：人文版模仿游戏——盲测裁判

原典与核心问题

图灵 1950 年《计算机器与智能》：如果提问者通过文字对话无法区分对方是人还是机器，就可认为机器具有智能。核心一问："看起来像"能不能作为"是"的判据？

教材对接：11.1 生成式 AI 进了人文书房；11.2 提示工程；11.3 RAG；11.5 幻觉、版权与学术诚信；11.6 署名、透明、不替代思考。伦理落点：盲测能骗过人眼，但骗不过证据核查。

时长50 分钟
分组裁判组 + 应答组
形式三轮盲测 + 幻觉标注 + 提示工程挑战
难度★★★☆☆

游戏流程

  1. 准备匿名答案（教师课前，10′）：就同一批古籍相关问题，准备三类答案各 3 条并编号为 A–I：①学生人工撰写；②LLM 裸答；③LLM+RAG（接入指定古籍语料）答案。全部隐去来源。
  2. 盲测投票（10′）：学生当裁判，读问题与 9 条答案，投票"哪些是人写的"，并给每条标注"有据 / 无据 / 无法判断"。
  3. 揭晓对账（8′）：公开来源，统计：裸答的幻觉率 vs RAG 的幻觉率；"把 AI 误认为人"的比例；学生标"有据"的答案中有多少其实无据。
  4. 提示工程挑战（15′）：学生分组写提示词，要求模型回答同一批问题时"必须引用原文、给出处、不确定则说明"。比谁的提示词带来的幻觉最少、证据最可查。
  5. 署名与透明（7′）：对照 11.6：如果你在论文中使用了刚才最优的 AI 答案，应该在何处声明、如何署名？"不替代思考"的边界在哪里？

材料与道具

  • 9 条匿名答案（人工/裸答/RAG 各 3）
  • 盲测投票表（来源判断 + 有据标注）
  • 提示词设计单

判定与产出

  • 胜出：幻觉率降低最多的提示词组
  • 产出：盲测表 + 幻觉率对照 + 提示模板
  • 必答：通过图灵测试 = 理解了吗？（回扣第4章中文房间）

讨论引导

  • 通过了图灵测试就等于"理解"吗？第4章的中文房间怎么回答这个问题？
  • RAG 为什么能减少幻觉？它的局限在哪——检索错了会怎样？
  • 如果 AI 答案比人写得更好，人还要不要署名？署名到底在声明什么？

学术诚信：盲测答案须由教师课前准备好，课堂不临时生成不可控内容；所有 AI 生成材料在揭晓后必须明确标注；提醒学生：课程作业中的 AI 使用必须按 11.6 声明。

教师提示与变体

答案来源：建议用教材第11章"用 RAG 问一本古籍"的案例准备材料，保证与本章一致。变体：把"人写的"换成"学生自己写的"，加入自我识别环节，冲击力更强。跨章联动：与第8章影像盲注并列，构成"语言幻觉 / 视觉幻觉"双实验。

12

电车难题 Trolley Problem · Foot

对接 第12章 人工智能前沿进展 ｜ 游戏：算法电车——当 AI 智能体替你扳道

原典与核心问题

富特 1967 年提出：失控电车将撞向五人，你能否扳道让车转向只撞一人？核心一问：当最优解必须牺牲某些人时，"最优"由谁定义、"责任"由谁承担？

教材对接：12.2 大模型与自动化数据分析；12.4 AI 智能体与数据工作流（MCP）；12.6 数据治理、版权与负责任 AI；12.8 算力、经费与学术共同体。伦理落点："负责任 AI"必须写进目标函数，而不是写在声明里。

时长50 分钟
分组4 个角色组（每组 3–4 人）
形式双难选择 + 角色辩论 + 目标函数改写 + 责任裁定
难度★★★★☆

游戏流程

  1. 设置两难（6′）：教师给出场景：某数字图书馆项目用 AI 智能体（MCP 工作流）批量数字化史料。选项 A——OCR 全自动，快且省钱，但会系统性误识某类少数民族文字；选项 B——人工逐字校勘，质量高，但导致其余馆藏无力数字化。全班先无记名投票。
  2. 智能体先扳道（6′）：教师宣布：智能体的目标函数是"单位成本处理页数最大化"，它自动选了 A。问：它错了吗？
  3. 角色辩论（18′）：四组分别扮演算法设计者、馆藏方、少数社群代表、伦理审查委员。每组陈述立场，并给出"如果由我定义目标函数，我会加上哪一条约束"。
  4. 改写目标函数（12′）：各组把"效率最大化"改写为含伦理约束的版本，例如"在少数文字识别准确率不低于 X% 的前提下最大化吞吐"。互换评估：这条约束可测量吗？会不会导致项目失败？
  5. 责任裁定（8′）：发"责任卡"：若误识造成史料失真，责任在开发者、部署者、还是模型？对照 12.6 与 12.8，写一份"负责任 AI 条款"。

材料与道具

  • 场景卡 + 选项 A/B 说明
  • 角色卡 4 套 + 责任卡 3 张
  • 目标函数改写单

判定与产出

  • 胜出：约束最可测量且最不回避代价的组
  • 产出：决策书 + 改写后的约束清单 + 责任声明
  • 加分：承认自己方案的成本与局限

讨论引导

  • 为什么"效率最大化"不够？它缺省了谁的价值？
  • "负责任 AI"具体要把什么写进约束？谁来验收这些约束？
  • 12.8 的算力与经费不均，如何加剧了这类两难？资源少的馆藏是否注定要承担更高风险？

教师点睛：电车难题的经典教训是"扳道的手不干净"。换个说法：智能体替你扳道，但方向盘仍是人设计的。把这句话写进课程思政的落点，比空谈"科技向善"更有力。

教师提示与变体

本土化：把场景换成地方志数字化中方言/少数民族史料的识别问题，与用户的方志研究背景高度契合。变体：用真实 MCP 工作流演示一次"自动决策"，让学生亲眼看到默认目标。提醒：角色辩论要避免把少数社群代表变成"哭诉者"，应赋予其专业数据包，让其论证有据。

谷堆悖论 Sorites Paradox

对接 第13章 综合项目与课程反思 ｜ 游戏：第几粒沙算研究？——结题答辩模拟法庭

原典与核心问题

古希腊麦加拉学派：一粒沙不成堆，再加一粒也不成堆——那么从哪一粒开始成"堆"？核心一问：当变化是连续的，我们如何为正当地划一条线？

教材对接：13.1 从"做实验"到"做研究"；13.2 好选题三要素；13.3 四要素闭环；13.4 评价量规（Rubric）；13.5 答辩与结课寄语。伦理落点：模糊的判断必须转化为可核查的证据，才能称为学术评价。

时长50 分钟
分组答辩组 + 评委组（轮换）
形式渐进卡片 + 模拟质询 + 阈值辩论 + 量规共建
难度★★★☆☆

游戏流程

  1. 发进度卡（5′）：教师准备 8 张渐进卡片，从"跑通一段代码"逐粒加沙到"完整可复现、有证据、有反思的研究"。每组抽一张，声称"我的项目已经是一项研究"。
  2. 模拟答辩（15′）：评委组依教材 13.4 的五个维度逐一质询："你的数据许可呢？""方法参数为何这样设？""结论有没有过界？"答辩组必须指出自己还差哪几粒沙。
  3. 阈值辩论（12′）：关键一问：从"演示"到"研究"，那条线应该画在第几粒？各组陈述并给出理由——是数据量？可复现性？还是反思的深度？
  4. 共建量规（12′）：全班把教材 13.4 的百分比维度，改写为"可观测的达标证据"。例如"数据合规 15%"改成"能出示许可文件 + 数据护照 + 引用格式"。
  5. 结课寄语（6′）：回到 13.5：方法组合不是目的，可复现、可解释、能说明局限，才使成果成为研究。请每人在卡片背面写下一句"我缺的那粒沙"。

材料与道具

  • 渐进进度卡 8 张/班
  • 教材 13.4 量规投影版
  • 量规改写表 + 结课卡片

判定与产出

  • 胜出：量规改写最可观测且答辩最诚实的一组
  • 产出：答辩记录 + 修订版量规 + 个人结课卡
  • 加分：主动承认自己项目的局限

讨论引导

  • 从"做实验"到"做研究"的临界点在哪？为什么它不可能是一个精确的数值？
  • 量规里的百分比（20%/15%/25%…）是精确的吗？它的作用是什么？
  • 13.3 的四要素闭环，如何把模糊的"堆"变成可核查的证据链？

教师点睛：谷堆悖论的实用答案不是"找到那一粒"，而是约定一条线并公开说明约定理由。这正是 Rubric 的哲学：评价的合法性来自程序的透明，而非阈值的绝对精确。以此收束全书，呼应第1章"可复现、案例真实、伦理在场"。

教师提示与变体

真实版：直接用学生本学期的小组项目作为进度卡素材，代入感最强。延伸：把全班修订的量规保留为下一届课程的评分依据，让学生体验"规则由被评价者共同制定"的治理感。提醒：质询环节要设定"对事不对人"的规则，避免演变成互相贬低。
