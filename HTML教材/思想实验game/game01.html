课堂游戏：数据身份盲盒——你是庄周，还是那只蝶？

把《齐物论》最著名的一问搬进课堂：同一份材料，在不同身份的观察者手里会长出两套完全不同的'真实'。这场游戏不是要学生选边站，而是让他们亲身体会——视角不是偏见，视角是条件；承认条件，才是学术诚信的起点。

01一、思想实验原典与展开

原典原文

昔者庄周梦为胡蝶，栩栩然胡蝶也，自喻适志与！不知周也。俄然觉，则蘧蘧然周也。不知周之梦为胡蝶与，胡蝶之梦为周与？周与胡蝶，则必有分矣，此之谓物化。 ——《庄子·齐物论》，郭象注、成玄英疏本
白话：从前庄周梦见自己变成蝴蝶，翩翩飞舞，惬意极了，全然忘了自己是庄周。忽然醒来，分明又是庄周。究竟是庄周梦见了蝴蝶，还是蝴蝶梦见了庄周？庄周与蝴蝶必定有别，这就叫"物化"。

提出者与时代

庄子（约公元前 369—前 286），名周，战国宋国蒙人。《齐物论》是《庄子》内篇的核心，主旨是消解是非、彼此、物我的固定界限。"梦蝶"是全书最短、也最被反复引用的一段寓言——它不论证，而是让人经历一次判断的失效。

思想实验的三层展开

  1. 第一层：判据失效。醒着时我们确信"这是真的"，梦中同样确信。两段时间里的确信感毫无差别，于是"我感觉真实"不能再作为真实性的判据。
  2. 第二层：主体边界的松动。不是"蝴蝶是假的"，而是在梦的那一刻，"庄周"这个主体根本不在场。观察者本身也是被呈现出来的。
  3. 第三层：物化。"周与胡蝶必有分"——差别确实存在，但差别是在某一次呈现内部才成立的。庄子的答案不是虚无，而是视角的不可通约。

后续变体与思想回响

  • 笛卡尔的"恶魔"（17 世纪）：用一个全能欺骗者把"梦蝶"变成方法论怀疑，最终逼出"我思故我在"。庄子停在怀疑本身，笛卡尔要找地基。
  • 普特南的"缸中之脑"（1981）：梦蝶的技术版本——感官信号全部由计算机提供时，"我如何知道我不是缸中之脑"？（本手册游戏 08 展开）
  • 当代 AI 版本：大模型生成的"世界描述"句句通顺、有据可查，但它从未"在场"。当一个模型描述某段历史时，它是庄周还是蝶？谁在梦谁？（与游戏 04、11 呼应）

常见误解

误解："庄周梦蝶是说一切都是幻觉，所以什么都不用认真。"
正解：庄子的落点是"物化"——视角转换本身是真实的事件。承认视角，不等于否定事实；恰恰相反，它要求我们说明自己站在哪个视角上。这正是教材 1.4 "伦理在场"的古典版本。

02二、与教材的对接

本游戏把第 1 章三个抽象命题变成可感的经验：

教材节点游戏中的对应物学生将获得的直觉
1.2 两个主角：数据科学与数字人文身份卡「蝴蝶」＝数据科学视角，「庄周」＝人文视角两种视角各自看见什么、各自漏掉什么
1.3.1 方法下沉（技术赋能人文）蝴蝶卡对统计表的第一写作规模与模式是技术能带来的增量
1.3.2 问题牵引（人文重塑技术）庄周卡追问「这张表为什么这样分类」人文问题决定技术该算什么
1.3.3 反思升维（人文超越技术）冲突点对读与投票视角冲突不能被算法自动裁决
1.4 可复现、案例真实、伦理在场同一证据卡 + 双视角声明可复现约束方法，不取消视角
一句话锚点：数据给的是"蝶的视角"，人文给的是"庄周的视角"；可复现约束的是方法，不是视角。这句话建议板书，并在第 13 章结课时重访。

04四、学习目标

完成本场游戏后，学生应能：
  • 辨识同一份材料在「人文视角」与「数据视角」下的不同呈现方式（识记层）。
  • 拆解一次观察中「看到了什么」与「用什么身份看」两件事如何纠缠（分析层）。
  • 说明为什么视角多元不等于事实相对主义，并给出「标注视角」的具体做法（反思层）。
  • 迁移到本课程：用一句话说清自己将来的研究站在哪个视角、漏掉了什么（迁移层）。

06六、游戏流程

  1. 抽身份、宣布规则
    4′

    每人 盲抽 一张身份卡。教师说明：庄周卡只能谈意义、语境、价值；蝴蝶卡只能谈可得、可测、可数。两组词汇表写在黑板上，越界即扣分。

    教师引导语：「现在你不是学生，你是这只身份。接下来 15 分钟，你不许说对方身份允许说的话。」
  2. 第一写作：以我之名
    7′

    各组拿到同一套证据卡 E1–E3。每人独立填写观察表左栏：「我看到了什么？这是什么？」庄周卡不少于 80 字，蝴蝶卡须含至少 3 个具体数字。

  3. 交换身份、第二写作
    7′

    组内互换身份卡，面对同一套证据再填右栏。教师提醒：不许回头看自己第一版。

    教师引导语：「材料一个字都没变，变的是你。请记住这种别扭——这就是视角。」
  4. 组内对读、标冲突点
    8′

    两人交换观察表，用红笔圈出「只有某个视角才看得到」和「两版直接打架」的地方；每组汇总至少 3 条到冲突点表。

  5. 抽组陈述、全班表决
    9′

    抽 3 组各 90 秒陈述。全班用三色贴纸投票：「哪一版更接近真实 / 是否需补证」。总记录员把冲突点写上黑板。

  6. 收束：回到 1.4
    3′

    教师指出：冲突无法由算法裁决；可复现约束的是方法，视角必须由研究者自己声明。布置 300 字「观察声明」作业。

08八、讨论引导（分层）

  1. 识记用一句话复述「梦蝶」的三层展开，并说出「物化」的字面意思。
  2. 分析两版观察表中，哪一处冲突是「数据没变、结论变了」造成的？请举出本组的具体例子。
  3. 分析1.3 的三种相遇方式（方法下沉 / 问题牵引 / 反思升维），分别偏向庄周还是蝴蝶？为什么？
  4. 反思庄周梦蝶是不是相对主义？如果不是，「承认视角」与「坚持事实」如何同时成立？
  5. 反思教材承诺「可复现、案例真实、伦理在场」——可复现能约束视角吗？如果不能，靠什么约束？
  6. 反思写 300 字「我的观察声明」：说明你在本课程中的研究将站在哪个视角、系统性漏掉什么。

10十、伦理与安全红线

教学红线：①身份卡只是视角工具，不得被用来贴" + "「人文＝感性 / 数据＝机械」的刻板标签；②投票结束后必须明确宣布：视角冲突不靠多数表决裁决，表决只用于显露分歧；③使用的志书书影须注明馆藏与许可，不得截取来源不明的图像。
大班控场：45 人同时写作时，若出现" + "「用对方口吻写」的投机行为，计时员直接提示该组重做。角色忠实是本场唯一的硬规则。

11十一、教师提示与变体

提示 1 · 课前准备与差异化
  • 快组加码：提前完成的组加做" + "「第三视角」——用「数据使用者」（如地方文旅开发者）的身份再写一遍。
  • 慢组支架：提供" + "「词汇 bank」：庄周卡可用——语境、意图、缺席、解释、价值；蝴蝶卡可用——计数、比例、缺失、可核查、分布。
  • 无黑板教室：用一张大白纸贴墙代替" + "「冲突点三栏」。
提示 2 · 变体与跨章联动
  • 变体 A：把身份卡换成 1.3 的" + "「方法下沉 / 问题牵引 / 反思升维」三卡，答案直接对应课程知识点。
  • 变体 B（线上）：用腾讯文档开两个分栏，两人同时编辑同一份证据，冲突处自动高亮。
  • 联动：本场与游戏 08（缸中之脑）构成" + "「古典怀疑 → 技术怀疑」的呼应；与游戏 11（图灵测试）构成" + "「谁在判断真实」的三连问。
提示 3 · 结课回收

把学生的" + "「观察声明」收齐，在第 13 章模拟答辩时发还——让他们对照学期初的自己，是否真的说清了" + "「我站在哪、我漏了什么」。这是全册最短、也最有效的前后测。
