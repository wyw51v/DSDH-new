01一、思想实验原典与展开

原典与情节

我生活在二维世界。这里的一切——包括我自己——都是平面图形。我们唯一的" + "「上下」是南北，唯一的" + "「左右」是东西。直到有一天，一个来自三维世界的球体穿过我的平面…… ——艾博特《平面国：多维度传奇》，1884（作者署名 A Square）

提出者与写作动机

埃德温·阿伯特（Edwin A. Abbott，1838—1926），英国牧师、数学教师与莎士比亚学者。《平面国》表面是数学寓言，实则是维多利亚时代的社会讽刺：二维世界的等级由边数决定（等腰三角形是工人、正方形是中产、圆形是教士），女性被画成危险的直线。这个讽刺提醒我们：空间的" + "「自然秩序」往往是社会建构。

思想实验的展开

  1. 维度的局限：二维居民看球体穿过平面，只能看到一个圆由小变大再变小——他们无法" + "「看见」球体本身，只能看见它的截面。
  2. 归纳的陷阱：他们根据有限经验建立" + "「世界只有二维」的信念，这个信念在经验内完全自洽。
  3. 更高维：当球体讲述三维，正方形 A Square 接受了；但当提到四维，球体自己又成了" + "「平面国居民」。每一层视角都有自己的盲区。

后续变体

  • 四维时空：黎曼几何与闵可夫斯基时空让" + "「时间作为第四维」成为科学常识。
  • Hinton 的四维立方体（超立方体）：用投影让三维生物理解四维——正如我们用" + "「时空立方体」让平面地图理解时间。
  • 历史 GIS（本游戏）：历史地图是" + "「二维截面」，时间维度被压扁。加上时间，因果判断会翻转。

常见误解

误解：" + "「平面国只是儿童数学读物。」
正解：它是尖锐的社会批判。把它用于 GIS 课堂时，最重要的不是" + "「三维很好玩」，而是每一种表征都有它系统性地看不见的东西——包括地图的边界与权力。

02二、与教材的对接

教材节点游戏对应机制习得的判断
7.1 给人文加一个坐标二维分布图坐标是一种选择
7.2 空间数据：点 / 线 / 面20 个地点坐标点数据的基本形态
7.3 历史 GIS：时间 + 空间时间纸条与时空图加维后结论翻转
7.4 空间分析：密度 / 邻近 / 扩散判断「哪里最严重」「向哪扩散」扩散需要时间才能判断
7.5 地理编码地名更改卡古今地名不一致的麻烦
7.6 地图即权力权力卡与地图声明边界、命名、取舍都是权力
一句话锚点：加一维，不只是加一个变量，而是加一种伦理立场。每一种表征都系统性地看不见某些东西。

03三、班级组织（40–45 人）

班级规模

40–45 人

11 组 × 4 人 = 44；余 1 人任" + "「球体使者」，负责投放维度卡。

组内角色

4 人 / 组
  • 平面居民 ×2（坚持第一版结论）
  • 球体使者 ×1（投放时间/层级卡）
  • 记录员 ×1（填对照表）

全班角色

1 人

" + "「总球体」由教师担任，掌控新一轮维度的投放节奏。

大班关键：不要让各组同时加维。统一投放：先全做二维，再由教师发时间纸条，最后发权力卡。这样才有" + "「集体翻案」的戏剧性。

04四、学习目标

完成本场游戏后，学生应能：
  • 描述二维地图在呈现扩散过程时的结构性局限（识记层）。
  • 绘制一张「空间 × 时间」的时空图，并据此修正结论（应用层）。
  • 分析行政层级与地名变更如何影响空间统计结果（分析层）。
  • 论证「地图即权力」的具体机制，并写出一份可核查的地图声明（反思层）。

06六、游戏流程

  1. 平面国：只看二维下结论
    8′

    发二维图，各组仅凭位置回答：「哪里最严重？扩散方向如何？」写下结论并签名——签名是为了后面「翻案」时有据可查。

    教师引导语：「你现在是平面国的居民。你没有时间的概念，只能看见这些点在哪里。」
  2. 球体闯入：加入时间维
    12′

    发时间纸条与层级卡。各组把时间当纵轴重画时空图。教师提示：注意「承平」这个点——它在图上最靠中心。

    教师引导语：「你刚才说中心最严重。现在看它的年份：1858。而边缘的安平是 1841。谁才是起点？」
  3. 平面居民的反驳
    8′

    每组 2 名「平面居民」坚持第一版结论，质疑加维后的解释。训练学生理解：维度局限不是愚蠢，是结构性的看不见。

  4. 权力卡：地图由谁划定
    12′

    发三张权力卡：①边界由谁定？②某县在统计年份被撤并/改名，密度图会怎样？③「哪些点值得画」由谁决定？各组填写地图声明。

  5. 收束与交换
    5′

    组间交换地图声明，找对方「没声明的立场」。教师点题：加一维不只是加变量，而是加伦理立场。

08八、讨论引导（分层）

  1. 识记说出点、线、面三种空间数据形态，并说明本游戏用到哪一种。
  2. 分析二维地图漏掉了什么？加上时间后，哪一点的「严重性」判断发生了翻转？
  3. 分析行政层级（府/州/县）不同，密度统计会怎样改变？
  4. 反思7.6 「地图即权力」在本案例中具体落在哪一步——边界？地名？还是「哪些点值得画」？
  5. 反思地名变更给地理编码（7.5）带来的麻烦，能靠技术解决吗，还是必须回到历史考据？
  6. 反思《平面国》原作也是等级讽刺小说。「空间的自然秩序」什么时候其实是社会建构？

10十、伦理与安全红线

教学红线：①SPOTS 数据为教学合成样例，不得当作真实灾害史引用；②" + "「改名撤并」卡涉及的地名须明确标注为虚构；③讨论" + "「未被记录的村庄」时，须强调这是史料覆盖问题，不是对现实地区的判断。

11十一、教师提示与变体

提示 1 · 数据准备
  • 底图：建议教师先用 Excel 散点图生成一张 0–10 网格图，投影+打印，省去手绘误差。
  • 关键设计：" + "「承平」(5,5) 位于中心却年份最晚(1858)，" + "「安平」(2,3) 偏僻却最早(1841)。这个反差是本游戏的全部张力所在，不要改动。
  • 时间紧：可只用 10 个点，保留" + "「承平 / 安平」两个关键对。
提示 2 · 变体与联动
  • 本地化：换成你所在城市的历史地名变迁，冲击力更强，但需确保数据可靠。
  • 进阶：用 QGIS 现场把点数据分层渲染 (按年代配色)，让学生看到" + "「制图软件替你做了选择」。
  • 联动：与游戏 05 对照——可视化决定" + "「看见什么」，维度决定「能看见什么」；再与游戏 09 的" + "「本体即世界观」呼应。
